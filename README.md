# GapBridge: 외국인 관광객 QR 결제 데이터 기반 소비 격차 진단 · 할인 프로모션 예산 배분

2026 제주 관광 데이터 활용사례 공모전 출품작의 분석 코드와 결과입니다.

## 구성

4인 팀 프로젝트입니다. 제가 맡은 부분은 **1-1 · 1-2 수요필터 · 소비갭, 1-5 도달대상, 3-1 · 3-2 갭브리지(할인 · 예산 시나리오), 대시보드의 관광 접근성 · 후보 선정 연결과 계절 시뮬레이션**입니다.

| 폴더 | 분석 |
|---|---|
| `1-1_1-2_demand_gap/` | 1-1 수요필터 · 1-2 소비갭 |
| `1-3_qr_gap/` | 1-3 QR공백 (분석 · 시각화) |
| `1-4_prescription_2x2/` | 1-4 처방유형 (최종은 전환형·객단가형 원인 분해) |
| `1-5_reach/` | 1-5 도달대상 · QR 가게매칭 |
| `2_did/` | 2 과거 프로모션 효과 DiD · 최소 검출 효과(MDE) |
| `3-1_3-2/` | 3-1 · 3-2 갭브리지 (할인·예산 시나리오) |
| `3-3_3-4/` | 3-3 집행 시뮬레이션 · 3-4 균등 배분 비교 |
| `4-1_4-3/` | 4-1 계절성 · 4-3 사전기간 재현 |
| `4-2_sensitivity/` | 4-2 민감도 (대상 선정 · 배분 결론) |
| `7_zone/` | 7 상권 실행안: 존 탐지 (DBSCAN) · 존 예산 / 관광 접근성 / 후보 선정 · 실행안 |
| `dashboard/` | Streamlit 대시보드 (진단 지도 · 동 상세 · 상권 지도 · 예산 시뮬레이터) |

## 분석 흐름

```
마스터 데이터 ─▶ 1-1 수요필터 / 1-2 소비갭
                    │
                    ├─▶ 1-3 QR공백
                    └─▶ 1-4 처방유형 (원인 분해)
                              │
              QR 가게매칭 ────┤
                              ▼
                        1-5 도달대상
                              │
     2 DiD·MDE (효과값 근거) ─┤
                              ▼
                       3-1 · 3-2 갭브리지
                              │
                              ▼
                  3-3 집행 시뮬레이션 · 3-4 균등 비교
                              │
                              ▼
          4-1 계절성 · 4-2 민감도 · 4-3 사전기간 재현
```

## 핵심 결과

| 단계 | 결과 |
|---|---|
| 1 진단 | 수요 필터 통과 37개 동 → 소비갭(중앙값 미만) 할인 배치 대상 18개 동 (전환형 13 · 객단가형 5) |
| 2 효과 | 동 단위 DiD로는 효과 미검출. 최소 검출 효과가 방문 +20%(시장)·+60%(애월)라 측정 단위 한계 → 효과값은 문헌값(0.44 / 1.10 / 2.22) 사용 |
| 3 배분 | 2개월 집행 가능액: 우리 배분 3.00억 vs 균등 2.28억(한도 도달), 2.08억 vs 1.65억(현재 소비) |
| 4 검증 | 대상 18개 동은 기준을 바꿔도 17\~18개 유지, 우리 배분 우위는 8개 가정 조합 모두 유지(1.13\~1.37배) |
