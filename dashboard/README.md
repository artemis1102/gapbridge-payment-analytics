# GapBridge 대시보드

외국인 할인 프로모션을 **어디에(진단) → 어떻게·누구에게(동 상세) → 어느 상권·가게에서(상권 지도) → 얼마나(예산 시뮬레이터)** 배치할지 보여주는 Streamlit 앱.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
브라우저에서 http://localhost:8501 이 열린다.

## 구성

| 파일 | 내용 |
|---|---|
| `app.py` | 대시보드 본체 (화면 4개) |
| `prepare_data.py` | 분석 결과 → `data/` 변환. 분석 결과가 바뀌면 이것만 다시 실행 |
| `data/dong.csv` | 43개 동: 진단 구분, 등급, 할인 조건, 타깃 국적, 예산, 운영 방식 |
| `data/zones.csv` | 할인 대상 동이 포함된 상권 존 77개 + 관광 접근성(팀원 A) + 트랙(팀원 B) |
| `data/zone_budget.csv` | 존별 예산 + 동별 존 밖 예산 (QR 확충 존 예산은 존 밖에 합침, `원래존예산`·`존밖합산예산`으로 추적) |
| `data/stores.csv` | 할인 대상 동 관광 업종 가게 (존 ID, QR 상태, 좌표) (공개 저장소 미포함, 루트 README 참고) |
| `data/sim_input.csv` | 시뮬레이터 입력 (18개 동 결제가능방문, QR가맹률, 계절 배율 등) |
| `data/jeju_dong.geojson` | 제주 43개 행정동 경계 (vuski/admdongkor ver20260701) |

## 화면

1. **진단 지도**: 43개 동을 할인 대상(전환형·객단가형) / 대상 아님 / 수요 부족으로 색칠. 동을 누르면 선택된다.
2. **동 상세**: 등급, 할인율·한도, 할인 방식, 최소 결제금액, 타깃 국적, 예산, 운영 방식(상권 집중형 / 혼합형 / 분산형 / 할인 존 없음). 운영 방식은 동 QR 가게 중 **할인 존** 안 비중으로 정한다 (QR 확충 존 제외, 원래 값은 `존안QR비중_전체존`).
3. **상권 지도**: 선택한 동의 상권 존(💳 할인 존 / 🔧 QR 확충 존), 존별 가게 수·QR 비율·관광 접근성·주변 관광지 TOP3·존 예산, 할인 존은 프로모션 공고(안) 카드, QR 확충 존은 "동 전역 할인에 포함" 안내 카드, QR 미확인 가게(업종별 보기 · QR 설치 시뮬레이션 · 영업 우선 리스트).
4. **예산 시뮬레이터**: 총예산·기간·등급별 할인율·집행 가정·시행 계절을 바꾸면 3-2 배분 알고리즘으로 다시 계산하고 균등 배분과 비교한다. 기본값(3억·2개월·20/15/10%)에서 보고서 수치(3.00억 vs 2.28억)와 같다.
